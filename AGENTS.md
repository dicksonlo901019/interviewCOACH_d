# Interview Coach repository instructions

The workspace-level `AGENTS.md` workflow and independent-review requirements remain fully applicable.

## Mandatory interview-content standard

Every new or revised interview strategy artifact in this repository must follow `INTERVIEW_CONTENT_STANDARD.md`.

Before presenting an interview guide, question bank, answer script, cheat sheet, mock interview, or interview website as complete:

1. Provide a glossary or explanation function for important terms and abbreviations.
2. Present a complete Traditional Chinese version first and a complete English version directly below it. Do not mix Chinese and English within one answer sentence.
3. Write spoken answers in direct, plain, concise language that sounds natural aloud.

For website artifacts, use the shared validation functions in `tests/helpers/interview-content-standard.mjs`. Register every published interview website in `interview-guides.json`; an unregistered website is incomplete.
